# WanderRo

Static travel website prepared for GitHub Pages.

## Structure

```text
WANro/
  index.html
  assets/
  css/
  js/
  .github/
  .git/          created locally after git init
```

## GitHub Pages

Upload this `WANro` folder as the repository root, then enable GitHub Pages:

1. Open the repository on GitHub.
2. Go to `Settings` -> `Pages`.
3. Choose `Deploy from a branch`.
4. Select branch `main` and folder `/ (root)`.
5. Save.

The site runs from `index.html`.
